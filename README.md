# Password Generator

## About the Project
Password Generator is a Python application that creates random passwords using lowercase letters, uppercase letters, numbers, and special characters.

## Features
- Generates random passwords.
- Supports uppercase and lowercase letters.
- Includes numbers and special characters.
- Allows users to specify the password length.
- Uses Python's `secrets` module for secure random selection.
- Handles invalid input.

## Technologies Used
- Python 3
- `secrets` module
- `string` module

## How to Run
1. Install Python 3 on your computer.
2. Open Command Prompt in the project folder.
3. Run the following command:

   ```bash
   python password_generator.py
   ```

4. Enter the required password length when prompted.
5. The generated password will be displayed on the screen.

**Note:** Enter a password length of at least 4 characters.
